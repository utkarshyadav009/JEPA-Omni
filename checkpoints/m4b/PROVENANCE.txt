── Architecture ──────────────────────────────────────────────────────────

  training loop at all (EasyCom has no matched M2/VGGSound feature cache).

── Data / session split ────────────────────────────────────────────────────
EasyCom Close_Microphone_Audio <-> Speech_Transcriptions pairs. SESSION-level
split (not random segment split -- only 7 distinct speakers total, segment-
level splitting would leak voice/room acoustics across train/test):
  train sessions = [1,2,3,4,5,6,7,8,9]   (3,370 segments)
  test sessions  = [10,11,12]            (1,112 segments), held out whole
Only Participant_IDs with their OWN Close_Microphone_Audio file are usable
(the AR-glasses wearer per session has no separate close-mic -- captured via
the array instead -- so wearer utterances are excluded). 15/338 annotation
chunk files are latin-1 encoded, not UTF-8; data/m4_speech_dataset.py
handles this.

── Gate results (checkpoints/m4b/best.pt, n=200 unless noted) ─────────────
(a) held-out transcription quality: WER=0.818, F1=0.332, cos=0.514.
  Honest read: high WER given EasyCom's difficulty (disfluencies, crosstalk)
  and very little training data (3,370 examples); short 1-3 word utterances
  inflate WER (single miss = 100%). Qualitative samples show real signal
  (several exact/near-exact matches).
(b) speech swap-control -- clean pass:
  cos(normal)=0.514; cos(swapped, TARGET)=0.136; cos(swapped, DONOR)=0.514
  (exact match to cos_normal -- swapped output tracks the donor's content
  precisely). F1 prior baselines (mode=0.086, random=0.024) well below 0.332.
(c)/(d) composition with M3 (checkpoints/m3_multigran_best) -- FAILED at
  this stage: (c) M3-with-speech collapsed to F1=0.000/0.000/0.001 (from a
  0.471/0.268/0.274 no-speech baseline). (d) M4b-with-M3 degraded to
  cos_normal=0.244 (from 0.517 standalone) but didn't collapse; swap-control
  structure survived. Root-caused via scripts/m4_diagnostic_dummy_tokens.py
  (dummy tokens partially degrade too -- real shape/length sensitivity, but

  FIXED by joint-exposure fine-tuning -- see checkpoints/m4_joint/PROVENANCE.txt.
